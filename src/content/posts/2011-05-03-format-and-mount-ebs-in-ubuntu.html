Once you have an EC2 server up and running with an extra EBS volume, there are a few steps to get the disk ready. I’m using the official Ubuntu 10.04 LTS image here. Double-check which disk you’re working on before you write to it. Formatting wipes what’s there. The steps below use /dev/sdX for both partitioning and formatting, so check whether you mean to format the whole disk or the partition you made.

Archive note. These commands are for Ubuntu 10.04 LTS. For a current EC2 instance, see AWS’s guide to identifying, formatting, and mounting an EBS volume.

  1. SSH into your instance
  2. mount
  3. take note of the /dev/sdX that is mounted i.e. /dev/sda1 on / type ext3 (rw)
  4. ls /dev
  5. take note of the /dev/sdX that is not the one from step 3
  6. fdisk /dev/sdX
  7. At "Command" type n
  8. at "Primary or Extended" type p
  9. At Number of volumes type 1
  10. Press "Return" two time to accept the defaults
  11. Press W to write the changes and exit
  12. type "mkfs.ext4 /dev/sdX" to format in Ext4
  13. type "mkdir /media/ebs"
  14. type "mount /dev/sdX /media/ebs" to mount the drive
